LumenClip is a content-production and automation workspace for social
slideshows, short-form video, and text posts. This documentation describes the
shipped system: how content is generated, what is persisted, what the interface
does, and what runs on a schedule.

## Start here

- **Tracing how a post gets made?** Start with
  [Output generation](/docs/workflows), which maps every pipeline from input to
  published artifact, including the model and provider at each generative stage.
- **Looking up a field, table, or endpoint?** Go to the
  [data dictionary](/docs/data). TypeScript definitions under `lib/` remain the
  executable source of truth.
- **Changing a screen?** Find the surface in the [UI field guide](/docs/ui),
  which is organized by destination and visible interaction state rather than by
  source file.
- **Debugging something that fires on its own?** See [Jobs](/docs/jobs) for
  scheduling, reminders, publication linking, and queue execution.

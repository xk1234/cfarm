Route: `/app?view=templates&template=<id>`

Legacy hook configuration moved into the template editor's prompt-style tabs. The shipped UI keeps hook editing with template style and generation controls.

The template-settings panel supports:

- hook count and tone controls
- hook ordering and quick edits
- hook case/quality transforms through content generation settings

If you have a legacy automation workflow reference, treat this route as the current
equivalent entry point while composing slideshow, video, or post outputs.

---
title: "Template settings"
description: "Shared settings surface for template behavior, output preferences, and scheduling defaults."
status: "WIP"
---

Route: `/app?view=templates&template=<id>`

The current settings surface for a selected template includes:

- output strategy settings
- prompt/style controls
- scheduling defaults (where supported)
- social account defaults
- format overrides

Status controls, scheduling, and publication metadata remain separate steps in the
publish pipeline once an output reaches the publish gate.

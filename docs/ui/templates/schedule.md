Route: `/app?view=templates&template=<id>`

Scheduling controls are still owned by the Template workspace and continue to apply
to template output generation flows.

High-level behavior:

- generated outputs inherit cadence from the template unless manually overridden
- projected publish windows are visible through the unified calendar
- schedule edits are reflected in the unified schedule report

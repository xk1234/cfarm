---
title: "Schedule page"
description: "Review and manage publications that have a future provider time."
---

The Schedule page is the workspace-wide publication calendar. It shows
generated outputs that were explicitly moved into a provider publishing flow,
including drafts, failures, scheduled posts, and published posts. Templates do
not create projected slots and have no recurring cadence.

## Event states

| State        | Meaning                                                         |
| ------------ | --------------------------------------------------------------- |
| Needs action | A generated output is waiting for a publishing decision.        |
| Draft        | A provider draft exists.                                        |
| Failed       | A publication request failed.                                   |
| Scheduled    | The provider is holding a post for a future time.               |
| Published    | The provider reports a live post or manual evidence was linked. |

Select an event to inspect the output, target accounts, scheduled or published
timestamps, provider status, and available links. A locally tracked scheduled
post with a stored content snapshot can be rescheduled or cancelled. These
actions only affect that publication.

For manual template runs and worker behavior, see [Template generation
jobs](./backend). For Telegram lifecycle notifications, see
[Reminders](./reminders).

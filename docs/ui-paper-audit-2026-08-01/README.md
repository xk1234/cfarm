# CFarm / LumenClip Paper-versus-application audit

Date: 1 August 2026.

Source of truth for the design side: the LumenClip Paper file, boards whose
names end in "Actual", exported at 1440 x 900 and 390 x 844 on 1 August 2026.
Those boards were traced against the shipped interface, so a disagreement means
either the tracing is stale or the application has moved.

The speculative "CFARM NN" concept boards were deliberately excluded. Comparing
an unbuilt concept against the app produces noise, not findings. Auditing those
as intended-future-state is a separate pass.

Every row cites the file and symbol that was checked. Severity is blocking,
notable, or cosmetic.

Totals across the three sections below: 8 blocking, 31 notable, 4 cosmetic.

## Could not verify

- The supplied artifacts are static PNG exports. Paper prototype links, hidden interaction frames, hover states, and any non-`Actual` boards were not available, so the audit cannot establish whether a visually missing action was wired elsewhere in Paper.
- The live production environment was not queried and no credential files were inspected. The repository proves the exact UGC kill switches and defaults, but the currently deployed value of `ENABLE_UGC_AUTOMATION` and provider-key presence were not independently read.
- Native `type="time"` presentation varies by browser and locale; only the code contract, not a live browser rendering, was checked because the audit prohibited running the dev server.

## Route/panel resolution

- **Workspace settings:** panels inside a modal owned by `RealFarmWorkspace`, not routes. `settingsOpen` is local state (`components/realfarm-workspace.tsx:182`), navigation opens it (`:831-843`), and the modal is conditionally mounted at `:1205-1210`. The desktop Paper boards correctly show an overlay; the mobile crop must not be interpreted as a standalone route.
- **Testing output trace:** the Paper composition is a dialog/panel, not a route. In the shipped repository that specific panel no longer exists: `/app/testing` redirects externally (`app/app/testing/page.tsx:3-5`). The separate inline `AutomationRunDebugModal` is a different, reduced debug panel (`components/realfarm/automation-settings/overview-panel.tsx:437-483`).
